# recursos/

Originales generados con Higgsfield (PNG) y capturas de revisión.
Las versiones optimizadas para web viven en `site/public/img/`.
Qué es cada uno y dónde va: ver `../SISTEMA-VISUAL.md`, sección 7.

- matcaps/   esferas de material (roca, esmeralda, oro), 1024², luz arriba-izquierda
- texturas/  grano de basalto, tileable por espejo
- posters/   hero 16:9 (fallback escritorio), 9:16 (móvil), bloque de roca (reservado)
- capturas/  hero por fases, móvil, styleguide completo, hojas de contacto
- capturas/producto/  pantallas de producto por rol (fase 4); los _vista-*.png son recortes a tamaño de pantalla
